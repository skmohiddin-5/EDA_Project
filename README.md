# Exploratory Data Analysis (EDA) Project

## Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to uncover patterns, trends, and relationships between variables. The analysis uses statistical summaries and visualizations to gain meaningful insights from the data.

## Objective

The objective of this project is to analyze passenger data and identify factors that influenced survival outcomes on the Titanic.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Dataset

The Titanic dataset (`train.csv`) contains passenger information including age, gender, fare, passenger class, family relationships, and survival status.

## Analysis Performed

* Dataset overview and structure analysis
* Missing value identification and handling
* Statistical summary generation
* Correlation analysis
* Distribution analysis
* Relationship analysis between features
* Visualization of important trends

## Visualizations

### Correlation Heatmap

Shows relationships between numerical variables.

### Survival Distribution

Displays the number of passengers who survived and did not survive.

### Passenger Class vs Survival

Analyzes the impact of ticket class on survival rates.

### Age Distribution by Survival

Compares age distributions between survivors and non-survivors.

### Fare vs Age Scatter Plot

Explores relationships between fare, age, and survival.

## Key Insights

* Passenger class significantly influenced survival chances.
* Higher fare-paying passengers generally had better survival rates.
* Survival patterns vary across different demographic groups.
* Age and fare provide useful information for understanding passenger outcomes.
* Correlation analysis reveals relationships among important variables.
